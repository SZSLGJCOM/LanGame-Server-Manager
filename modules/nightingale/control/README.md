# Current-world native save

Starting the instance automatically prepares its independent runtime, installs and configures the fixed official UE4SS **3.0.1-1125-g527a483b** loader with its genuine `dwmapi.dll` proxy, and publishes the owned `LgsmWorldSave` policy and native bridge before creating the game process. The archive/core/proxy are hash-verified; required [native-save settings](../../abioticfactor/control/UE4SS-settings.ini) are merged while preserving unrelated configuration, comments and existing Mods. A compatible verified loader can be reused; ambiguous entries, unknown core/proxy files and externally edited owned files are preserved and reported as conflicts. Owned interrupted publication can resume. Shared program files remain untouched. The private payload contains `Scripts/main.lua`, `enabled.txt` and `native/LgsmNightingaleSaveControl.dll` plus the ownership marker.

The bridge is closed to Steam build **22204011**, Shipping SHA-256 `8e06c60524066655aee66da2e06b52c702a951afc3c28b59a2923f9dd51bd7eb`, and loader SHA-256 `91d5444f41d19d0bb502f0fbdc15d76421e20359e898caa39e41e134c8f87958`. Both the host and in-process bridge pin and hash their real files. Its export has no Lua ABI imports: the owned Lua policy publishes a bounded closed native request, invokes the fixed DLL export, and verifies the nonce, operation, PID and process-creation identity of its receipt.

| Fixed-image evidence | Contract |
| --- | --- |
| Periodic-save closure, RVA `0x3f8d190` | Takes only a pointer to its captured `UWorldPersistenceSubsystem*`. Derives the periodic filename from the current native world, calls `SaveWorldState` with its asynchronous flag true, then emits the normal periodic-save notification. |
| `SaveWorldState`, RVA `0x3f9c540` | Rejects persistence-disabled state and an expected-but-not-applied persistence load before serializing the world and queuing the normal persistence writer. This path neither exits the server nor substitutes a backup. |
| Class singleton, RVA `0x9f551e0` | Exact `/Script/NWXWorldPersistence.WorldPersistenceSubsystem`; its outer is the current game instance. |
| Subsystem `0x60`, native weak resolver `0x1594190` | Resolves the exact current world and compares it with the Lua request's world address. Saving-enabled byte is at `0x90`; native persistence state is at `0x48`, with the load-required/applied guard at `0x370/0x371`. |

World selection and native snapshot serialization run on EngineTick. The owned worker writes the captured JSON through the native synchronous storage branch without accessing UObjects; EngineTick rechecks the same world and storage identity before a final receipt. The protocol selects the unique authoritative GameNetDriver, its begun-play world, game state, game mode and owning game instance. Selecting the driver avoids enumerating the hundreds of static/level-instance World assets in a normal realm. The subsystem must belong to that game instance; the native weak-world resolution, class, ownership, readiness and fixed prologue are checked again before invocation. Boot/world tokens, a process-only launch token, native process identity and short admission deadlines bind the exchange to the current managed launch. A bounded native replay table records an unknown receipt before entry. Exceptions, deadline races and missing receipts never resend the effect.

The current adapter takes one snapshot through `SerializeWorldSession` (`0x3f9c440`), then calls the exact native `SaveJsonToServicesAndFile` helper (`0x3f9bab0`) once with the synchronous SDK branch. It accepts only the verified offline in-process backend, configured namespace, current token identity, record and state writer. The worker reads the resulting private `NWX/Saved/Offline/<provider>/Deploy/<record>/state`, fully validates its gzip stream and compares decompressed length/SHA-256 with this request's captured native snapshot. A normal function return alone cannot confirm persistence. A completion receipt additionally requires the original process, world, subsystem, backend, token provider/principal and record to remain bound to this request. Timeouts, unknown outcomes and exceptions never resend it.

The offline writer decodes its request token at `0x3d51d00` and uses the JWT `prv` claim for the provider directory; the module's configured namespace at `0xe8` is a separate value and may be empty. The adapter follows the same current client-token/server-token selection through `0x3d20f20`, the same native JWT decoder (`0x3d3c9a0`) and both `prv`/`prvid` fields. It then calls the writer's native directory/record path builders (`0x3d51f50` / `0x3d52060`) and requires their normalized result to equal the exact private root plus validated provider and record leaves. Tokens and claim contents are never written to diagnostics.

The module-name constructor at `0x120cee0` is the ANSI FName overload; its argument matches the original ASCII `NWXOnlineServices` literal. The native file writer normalizes relative paths through `0x1199b80`/`0x1199be0` using the engine BaseDir getter at `0x122f100`. The adapter verifies that base against the Shipping directory and resolves ProjectSavedDir from it, then requires the exact private `NWX/Saved` root. The bootstrap's inherited Win32 working directory is not used as an engine path substitute.

`Persistence.SaveWorld` and `Persistence.SaveWorldAsync` console registration callbacks in this Shipping build only build/release strings. They are not persistence acknowledgements. The HTTP status endpoint also remains read only.

The Lua dispatcher separately tracks `queued`, `preparing`, `executing`, `pending` and `observing`. Each EngineTick queue still expires after three seconds. Immediately before the first native entry, the Nightingale policy validates the current world and original frame, then marks that exact operation entered; synchronous snapshot generation and subsequent readback use the existing thirty-second request completion budget. A long snapshot cannot be mistaken for queue delay, and observation never renews that original budget. Dispatch ownership belongs to the operation object, so an expired callback cannot release or replace a newer operation's dispatch or result.

## Verification scope

The strict `/W4 /WX` native build and malformed-frame checks cover the closed bridge. The Lua regression executes the actual game policy and shared protocol across ownership, world replacement, nonce/process mismatch, bounded pending polling, no automatic resend, timeout races and rejection of void/unknown receipts. Exact fixed-image prologue checks also cover the native storage and path helpers. These component checks do not establish native game acceptance.

An isolated component probe maps the hash-pinned original Shipping image without executing its server entry. The actual native JWT decoder, field reader, shared-object destruction and path builders accept a synthetic provider/principal token, reject malformed/missing claims, and produce the provider path that differs from the former empty-namespace path. Only the host allocator, engine-version initialization and fixture SavedDir are supplied at the host boundary; core parsing and path construction remain native. Production still requires the full manager acceptance below.

The earlier disposable native trial proved that the previous periodic API could be invoked and its realm could be reloaded. It did not provide a request-correlated write acknowledgement. The current snapshot/readback implementation requires a fresh full manager save, normal stop, restart and second save acceptance. Until that passes it is not recorded as a completed native adapter. The public operation reports a verification failure when it cannot certify the complete result itself; it does not return a successful command-delivery notice asking the operator to check files.
