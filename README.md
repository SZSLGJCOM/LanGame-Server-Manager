# LanGame Server Manager

[简体中文](README.md) | [English](README.en.md)

[官网](https://langame.cn/) · [产品页](https://langame.cn/products/langame-server-manager/) · [使用文档](docs/README.md#简体中文) · [开服教程](https://langame.cn/hosting/)

LanGame Server Manager 是一款 Windows 桌面应用，用来安装、配置和运维游戏专用服务器，闲置的旧笔记本、旧电脑或 Windows Server 都能当服务器。

## 功能

- 一键安装专服，自动准备 SteamCMD 和所需运行库
- 按游戏编辑原生配置，多实例互相隔离
- Mod 安装、更新与管理
- 内置 LanGameCMD 托管服务器，告别烦人的 CMD 黑框弹窗
- 资源与实例状态监控
- 玩家管理，以及部分游戏支持的 GM 工具
- 存档导入与备份恢复
- 可选的 LAN AI 助手（使用自己的模型服务）

支持 [32 款游戏](docs/games.md#简体中文)。

## 下载与开始

从 [GitHub Releases](https://github.com/SZSLGJCOM/LanGame-Server-Manager/releases) 下载 Windows 安装包，安装后在应用中添加服务器即可。支持 Windows 10 / 11 和 Windows Server。

同一局域网可直接联机，也可搭配 Radmin VPN、Hamachi 等组网工具；公网联机时应用会自动配置 Windows 防火墙规则，路由器端口映射需自行设置，详见[联机教程](https://langame.cn/networking/)。
