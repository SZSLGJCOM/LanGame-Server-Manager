# Return to Moria native player console evidence

`evidence.json` records bounded, isolated Windows runtime probes of Steam app 3349480 build 21872765 on 2026-09-08. It is protocol investigation evidence, not a configuration acceptance fixture.

The [official command guide](https://northbeachgames.freshdesk.com/support/solutions/articles/154000217148-commands-while-the-server-is-running) documents `players`, `help`, and `exit`. The zero-player response and unknown-command nonce echo were observed in the scratch server's native console with no clients connected. Probe-specific paths, credentials, invite codes and process IDs are omitted. The nonce placeholder is identified as normalization in the evidence file.

The native executable independently creates a Windows console outside ConPTY. Reading and writing that console from an isolated helper worked, while ConPTY did not receive the output. Disabling the native console and enabling Unreal stdout/ExecCmds did not provide the player CLI. `Status.json` contains a count string and no online identity array.

The module declares a read-only native-console collector. A short-lived copy of the desktop executable owns console attachment, holding verified bootstrap and shipping-process identities. It writes only a random begin marker, `players`, and an end marker; the IPC pipe is duplicated before attachment. Capture is bounded to 256 physical rows and 64 KiB of response text. Resized, wrapped, rewritten, incomplete or partially connected output fails without inventing entries. Already observed frame content must remain an identical prefix even when ordinary physical scrollback shifts rows.

`empty.txt` normalizes the observed zero-player response and unknown-command response shapes into the bridge's begin/end framing. `normal.txt` is explicitly synthetic: it combines the installed first-party row format with fabricated labels, duplicate names and non-ASCII text. Neither file is evidence of a populated live server. The native unescaped `name (opaque)` label is preserved in full; the parenthesized value is not presented as an account ID, and no moderation action binding is issued. Tests cover response correlation, exact counts, partial connections, line injection, row wrapping, scrollback rewriting and identity mismatches.

The production bridge was accepted on the same isolated package on 2026-09-08. `native_console_owned_moria_empty_server_end_to_end` launched the real `MoriaServer.exe` through `spawn_launch_plan` with the module's background managed-terminal policy, on a private hidden desktop. The collector started from the production-registered bootstrap PID and resolved only its verified shipping descendant. The built desktop helper returned two different complete nonce-framed `Players: 0/8` replies over its private pipe. Startup queries failed until the clean native prompt was ready. The native-console suite covers pipe-tail delivery, owned-helper cleanup, Win32 ABI and frame integrity. Owned-process cleanup completed and no game/helper process remained. This run used bounded forced cleanup of the scratch tree, not a graceful-exit assertion.
