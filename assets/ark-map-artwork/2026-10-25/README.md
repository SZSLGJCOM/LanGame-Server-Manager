# ARK map artwork · 2026-10-25

19 original ARK Wiki JPEGs for LanGame Server Manager's map workbench.
The manifest records original sources, file-page rights notices, image
dimensions, GPS bounds and SHA-256. Images retain their upstream rights;
the project's source-code license does not cover them. See NOTICE.md.

This version directory is immutable. A changed image requires a new
version directory, coordinate review, checksum and mirror verification.
GitHub and GitCode copies use identical bytes. The application selects
its download source by interface language and caches verified images.
